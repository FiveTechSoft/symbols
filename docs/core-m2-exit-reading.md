## Limits

- One runner and one account for the Windows cells; Linux cells on `ubuntu` only.
- Local bare remotes only; no hosted-remote behaviour (auth, hooks, branch protection) is covered.
- No power-loss or process-kill claim for the git sequence.
- Cooperating writers only.
- `syntax_ok` in `src/git_ops.c` treats exit code 127 as "no compiler". 127 comes from the POSIX shell path. A configure-time probe (m130, run 37202049544, `CMakeLists.txt`, kept on master) measured on the Windows jobs: `cmd /c where gcc` rc 0 (`C:\mingw64\bin\gcc.exe`, then `C:\Strawberry\c\bin\gcc.exe`), `cmd /c gcc --version` rc 0 (gcc 15.2.0, MinGW-Builds), and a missing command under `cmd /c` exits 1, not 127. So on a Windows machine without `gcc`, `syntax_ok` would count a failed compile, and `revert_head` should then refuse because the previous-version compile must pass; that refusal path was NOT run (it is a reading of the source). The gcc evidence is for this runner image only and can change when the `windows-latest` image does.
- Not examined for Windows clients: `src/server_taskops.c` builds `git checkout HEAD~1 -- '%s'` strings with single quotes for a client `bash` tool. cmd.exe does not strip single quotes; whether any Windows client runs these through cmd.exe was not looked at. `git_ops.c` itself builds unquoted commands from paths that passed a character whitelist.
- Scope of the Git contracts, read in the source in m227 and not measured: `src/agent_runner.c` contains no call to `AgentGit*`, `git_gate` or `git_ops`. The in-process patch path (`PatchVerifyPlan`, then `PatchApplyAtomic`, called from `src/agent_runner.c`) therefore has no preflight, no dirty-tree or HEAD check and no Git rollback; its safety rests on the verify step, the file-level atomic replace and `PatchRollback`. Criterion 5 and the parked workflow decision concern `.github/workflows/apply-patch.yml`, not this path; this paragraph only says that "apply must use the Git contracts" is not true of the in-process path today and that no test here measures that path against a dirty or stale tree.
