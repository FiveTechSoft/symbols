## Exact v2 contract, not a blanket +1 allowance

Retain private positive control (witness/status/mask5), deliberately invalid private cmd.exe (64X bytes), direct native loader probe errors193/216, all exact launch-failure result/capture/witness oracles. Use the same unmodified AgentShellExec linked from symbolic, never the private instrumented variant.

Measure baseline and immediately after EACH of27 rejected API calls (3+12+12), before diagnostic output. Delta MUST be exactly1 after call1 and exactly1 after every later call. Flat0 is NOT accepted by v2; +2, delayed increase, later decrease, or any later growth is red. Do not rebaseline. Extend the existing3-call observation to27, preserving first three call invariants and retaining all27 result masks0.

At paused checkpoints, a separate parent performs documented PSS handle-table capture using precreated events/shared mapping (not pipes). Compare every baseline entry's handle value/type/name bytes/flags across all checkpoints; complete enumeration count must match child's own GetProcessHandleCount. Require exactly one added entry at first completed call; it must be a counted UTF-16 type File (4chars or4+singleterminalNUL via existing validated helper) with HAVE_TYPE. Every later table must equal baseline plus that same candidate under the observable PSS metadata. Extra, removed, changed baseline entries, changed candidate, missing type, incomplete capture or encoding error are red even if totalcount stays+1.

PSS metadata equality does not prove kernel-object identity across arbitrary close/reopen of an equal-valued handle. Describe the implemented check precisely; no owner/lifetime theorem. No instrumentation/close of candidate to claim such proof.

While the actual shell failure child remains paused after call1 and again after call27, query the candidate resource using the previously controlled isolated helper with DuplicateHandle (no DUPLICATE_CLOSE_SOURCE), GetFileType and GetFinalPathNameByHandleW(FILE_NAME_OPENED|VOLUME_NAME_NT). Require FILE_TYPE_PIPE3 and exact counted path `\Device\NamedPipe\` length18, not prefix, child pipe name, slash-normalization or substring. Literal relative `\` alone is insufficient. Candidate source handle remains open and unchanged before/after each query, verified by complete duplicate PSS captures and child count. Close only the query helper's duplicate and own harness resources, never the source candidate. Query failure/pending/timeout/malformed string/cleanup failure is red. No need to require native relative-name query as a second resource oracle; retained historical query evidence is separate.

Observer controls are mandatory in new test: fresh no-shell-call child with same harness setup and repeated PSS/query-neutral checkpoints must stay flat with identical tables; actual failure arm duplicate baseline snapshots must agree. A count-only fresh actual AgentShellExec failure arm must show the same27-call pattern without PSS/resource queries, or report observer effect and keep red. Positive control stays in fresh process, cannot warm the invalid arm's pipe runtime. Query helper controls cover known ordinary temp file/known pipe, invalid handle and bounded stalled-helper cleanup before candidate interpretation.
