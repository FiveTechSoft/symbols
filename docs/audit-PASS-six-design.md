## Mechanism, evidence and non-claim

CMake documents PASS_REGULAR_EXPRESSION as a list (semicolon separates alternatives) that ignores ordinary exit code. The current dual-stream marker prints native cases=5 even on failures>0/exit1; snapshot logs print earlier complete=1 before later failure. aliases_short, lock_alias and sweep_foreign return0 while printing measured tables; CMake holds their expected values. batch_replace holds a two-part measurement line in CMake. Dropping PASS without a replacement loses their measurement oracle. Successful historical CTest rows do not prove all six full transcripts met their oracle. No historical 'all six fully passed' claim is made.

## Proposed gate

One new Python runner tests/windows_six_gate.py, frozen expected transcripts in tests/windows_six_gate_gold.json, one cross-platform selftest tests/test_windows_six_gate.py, docs/audit-PASS-six-design.md, and CMakeLists.txt: five paths. Required source emitters stay byte-identical. Six existing test names retained, changed command only: Python runner --kind KIND -- NATIVE [existing args]. Preserve working directories, target dependencies, arguments and native binaries. Remove PASS_REGULAR_EXPRESSION from those six tests only. No WILL_FAIL, no skip-on-error, no acceptance of mutant nonzero. Existing native test exit0 is always required in addition to the output contract.

Output contract: strict UTF-8 (ASCII-selected markers; existing resource filenames use the current emitted escaping); allow CRLF or LF framing, not arbitrary strip/case folding/substring. Require exactly one expected complete final line as the last nonempty line. Preserve internal spaces, delimiters, every field and every group from the pre-existing expected CMake string. Do not tune them to new observed native output, even if the stricter gate turns red. Preserve stdout/stderr logs in one merged stream for ordering and child diagnostics (batch_replace intentionally emits child-status stderr); nonzero exit always rejects. The runner prints native transcript before a gate result, including partial output on errors. Decode errors/launch errors/timeouts reject, never skip. No claim of descendant cleanup on Python timeout: subprocess timeout terminates its direct child; existing native job/process cleanup remains its own contract, and outer CTest timeout is retained.

Snapshot additionally requires all three unique PSS_ARM complete=1 summaries in order: count_only_pipe0,3,1,3,1; snapshot_only_no_pipe0,0,0,0,0; external_snapshot_pipe0,3,1,3,1. These exact deltas/arms are already checked by the unmodified native producer, not new ownership semantics. Final line alone cannot certify its intermediate protocol, so this guards the known control-only false green. Do not reuse/modify frozen v2 gate or claim the snapshot's persistent candidate has a proven owner/retainer or may be closed.

Dual full final line requires failures=0 AND native cases=5. Its five real observations stay in producer, no new mode/buffer expectedvalues invented. Table gates compare one full line with ALL existing groups. batch_replace compares the entire chained-count+summary line. All line literals are pre-code frozen from CMake, not a current measurement claim.
